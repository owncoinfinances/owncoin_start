# OWNCOIN

Gestor financiero personal: cuentas, tarjetas de crédito, tasa cero y presupuestos.

- La app no contiene datos. Tus datos viven en tu navegador y, si conectas GitHub, en tu repositorio **privado** de datos.
- Respaldos en formato `.json` propio de OWNCOIN.
- Se instala como aplicación desde GitHub Pages (`manifest.webmanifest` + `sw.js`).

Para actualizar la app, reemplaza `index.html` (y `sw.js` si cambia) en este repositorio.
